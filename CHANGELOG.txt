E-Class Record App with GS and SF9 — v1.0.5

NEW
- Bundled the supplied official Class Record Excel template under templates/.
- Added Download Official ECR (.xlsx) in Class Record view.
- Class Record printing now generates the official XLSX and opens it in the default spreadsheet app for printing.
- Term 1, Term 2 and Term 3 exports reuse the official layout and update the term label/sheet name automatically.
- Automatically fills Region, Division, School ID, School Name, School Year, Grade Level, Section, Teacher and Subject.
- Automatically fills HPS, raw scores, totals, PS, WS, component examination percentages, Initial Grade, Term Grade and Descriptor.
- Learners are placed in the template's MALE/FEMALE sections (up to 50 each).
- Export validation requires the official template's fixed 5 WW / 3 PT / 3 EX structure.
- The exported copy is static and standalone: original external INPUT DATA / HELPER links and calc-chain metadata are removed.
- Master template formatting, merged cells, drawings/logos, page setup, margins and print area are preserved.
- The master template is never overwritten.

E-Class Record App with GS and SF9 — v1.0.4

NEW
- Added Import Scores CSV in every Term Class Record.
- CSV importer auto-detects learner-name/LRN columns and common score headers such as WW1, PT1, ST1, and TE.
- Added a mapping screen so CSV columns from different offline Excel class-record formats can be matched to the app's current WW/PT/EXAM components before importing.
- Learners are matched by LRN first, then by normalized name.
- Optional: add unmatched learners from the CSV to the roster.
- Safe default preserves existing raw scores; optional overwrite can be enabled during import.
- Invalid numeric values and values above the app component HPS are skipped and reported.
- Imported raw scores automatically feed the existing PS, WS, Initial Grade, Term Grade, GS, and SF9 calculations.
