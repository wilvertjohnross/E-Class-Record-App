E-Class Record App with GS and SF9

Version 1.0.3
- Added a global Upload / Change School Logo control under Setup.
- The selected school logo is used automatically in the Class Record, Grading Sheet, and SF9.
- School logo selection applies to every class in the app and is stored with the gradebook data/backups.
- Added Reset to Default for the school logo.
- Uploaded logos are resized to a maximum of 700 px and stored as PNG for efficient offline use.
- DepEd seal and DepEd wordmark remain fixed and unchanged.
- No changes to grade calculations, class data, GS/SF9 grading logic, or printing behavior.

Version 1.0.2
- Fixed the + New Class button in the Electron desktop app.
- Replaced the unsupported browser prompt() used by New Class with a native-looking in-app dialog.
- The new dialog supports Create Class, Cancel, Enter to submit, Escape to cancel, and required-name validation.
- Replaced the second prompt() dependency used by Roster > Paste names with the same desktop-safe dialog system.
- No changes to grade calculations, class data structure, GS/SF9 layouts, or saved-data format.

Version 1.0.1
- Fixed "This app doesn't support print preview" when using in-app Print buttons.
- Class Record and Grading Sheet now open the native Windows print dialog.
- Single-learner and all-learners SF9 printing now use the same native print path.
- Retained print backgrounds and the existing A4 print CSS/layout rules.
- No changes to grade calculations or stored gradebook data format.

Version 1.0.0
- Initial standalone Electron release.
