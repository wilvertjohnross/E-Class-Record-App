# KLAS v1.5.0 — Visual Contract

The approved mockup is the visual target for v1.5.0.

- Preserve the previously approved KLAS logo/banner artwork.
- Sidebar is narrow and shows only Home, Class Overview, Advisory Overview, and Grading as passive location indicators.
- Dark Mode, Import Backup, and Export Backup remain active sidebar utilities.
- Home and Return controls sit at the upper-right of work pages.
- Dashboard headings are centered.
- Dashboard launchers use small translucent rounded tiles, colorful icons, minimal text, and generous spacing.
- Large statistics strips, status pills, nested sidebar entries, and heavy dashboard panels are not part of the approved visual direction.
- Backgrounds are realistic but strongly blurred/faded so controls remain dominant.
- Launcher hover/keyboard focus uses subtle lift/pop motion; press uses a short tactile response; reduced-motion disables movement.
- Functional labels and available actions must reflect real KLAS workflows even where the generative mockup contained illustrative or inaccurate labels.
