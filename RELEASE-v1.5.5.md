# KLAS v1.5.5 release notes

- Class Overview reuses the existing Class Adviser field and displays the selected class name and school year.
- The three Class Overview cards are centered as a group.
- Learner Roster shows total, male and female learner counts, including unspecified sex where present.
- Details and counts update when the subject class changes. No duplicate adviser field or changes to grading formulas/data domains.
