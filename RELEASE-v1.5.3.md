# KLAS v1.5.3 release notes

- Fixed duplicate right-side scrollbars. The main background uses non-scrolling clipping, leaving the document as the page scroll area and keeping the desktop sidebar in place. Table-specific scrolling remains available.
- Removed LRN and Age columns from Class Overview > Learner Roster. The Subject Teacher roster retains learner name, sex and removal controls. Previously stored LRN/age values remain intact; adviser form fields and data are unchanged.
- Grading calculations, examination settings, keyboard shortcuts and class-switching behavior are unchanged.
