E-Class Record App with GS and SF9
v1.1.0 — SF2 Daily Attendance Integration
Five-Pass Release Gate

Scope
-----
Feature-level release adding official School Form 2 (SF2) Daily Attendance while preserving the v1.0.27 ECR/GS/SF9, persistence, security, and dark-theme baseline.
This is a FULL BOOTSTRAP release because the trusted Electron main-process IPC allowlist now includes SF2 official-output actions.

PASS 1 — PACKAGE / TEMPLATE INTEGRITY: PASS
- package.json version: 1.1.0.
- JavaScript syntax checks passed for main.js, preload.js, thread-updater.js, main-extension.js, sf1-parser.js, app/app.js, and tools/make-thread-update.js.
- Official ECR and GS template files are byte-identical to v1.0.27.
- Bundled templates/SF2 official Template.xlsx is byte-identical to the user-supplied School Form 2 workbook.
- SF2 source-template SHA-256: 2fe5668f6fd86ce7cb7a1cc2f76ac2e6e35bc20d3b80d779ce459000c0c9d4ba.
- ECR, GS, and SF2 workbooks pass ZIP integrity checks.
- No private signing key / PRIVATE KEY PEM material is present in the source tree.

PASS 2 — ELECTRON / UPDATER SECURITY: PASS
- preload.js and thread-updater.js are byte-identical to the v1.0.27 baseline.
- main.js change is constrained to the three trusted SF2 runtime actions:
  sf2:official-pdf-preview, sf2:official-popup-preview, sf2:official-save.
- Content Security Policy is unchanged: local-only scripts/resources; connect-src none; object/frame/base/form restricted.
- No eval() or new Function() introduced.
- SF2 preview popup uses contextIsolation, sandboxing, nodeIntegration:false, navigation blocking, and popup denial consistent with ECR/GS previews.
- Future local-update creator now declares minBootstrapVersion 1.1.0; v1.1.0 itself must be installed as a full bootstrap.
- Existing Ed25519 update key ID remains ecr-dev-2026-02; the private key is not bundled.

PASS 3 — DATA INTEGRITY / ATTENDANCE LOGIC: PASS
- SF2 is opt-in per class through Setup -> SF2 / Advisory Class. Subject-only classes do not expose the SF2 tab by default.
- App-owned attendance codes: P/blank Present, A/× Absent, L/upper-half Late Comer, C/lower-half Cutting Classes.
- Default school days are Monday-Friday; user can include/exclude dates; official output is capped at 25 school days.
- Learner calculations verified: class days, present, absent, tardy, and maximum consecutive absence run.
- 5-consecutive-absence detection verified, including reset by non-absence marks.
- Monthly computations verified against the formulas printed in the supplied SF2 template:
  Percentage of Enrolment = Registered End / Enrolment 1st Friday of June x 100;
  ADA = Total Daily Attendance / Number of School Days;
  Percentage Attendance = ADA / Registered End x 100.
- SF2 -> SF9 synchronization verified. Existing conflicting SF9 attendance is overwritten from maintained SF2 months, and corresponding SF9 attendance inputs are read-only while SF2 is authoritative.
- Learner deletion removes that learner's SF2 marks/remarks.
- Backup import validation now bounds and validates SF2 months, dates, codes, remarks, and summary values; valid SF2 backup accepted and malformed cases rejected in tests.

PASS 4 — OFFICIAL SF2 OUTPUT / EXISTING FORM REGRESSION: PASS
- Official template structure analyzed as A1:AJ93 with 179 merged ranges, 25 daily-attendance columns, 21 Male learner rows, and 25 Female learner rows.
- The supplied master template remains byte-for-byte unchanged in the package.
- Generated SF2 copy preserves all 179 merges, styles, drawing definition, embedded images, printer settings, margins/page setup, and print-view metadata tested.
- Generated SF2 writes only app-owned values to official data-bearing cells: header, date/day columns, learner names, attendance symbols, totals, remarks, summary, Adviser, and School Head.
- Generated SF2 contains 0 formulas, 0 external-link files, and 0 #REF! defined-name residue. The source template's stale external-link/broken-name residue is cleaned only in generated copies.
- Generated test SF2 passes XLSX ZIP integrity and key-cell mapping checks.
- Validation rejects >25 school days, >21 Male learners, >25 Female learners, and unsupported attendance codes.
- ECR and GS regression check: expanded generated workbook contents from v1.1.0 are identical to v1.0.27 for the same test payloads.
- Existing official ECR/GS template bytes are unchanged.

PASS 5 — RUNTIME / UI / EDGE CASES: PASS
- SF2 tab appears only after enabling SF2 for the class.
- Month selector follows the app's existing June-April SF9 school-year sequence.
- Working grid supports click cycling and keyboard P, X/A, L, C entry; Present remains visually blank.
- Invalid SF2 summary values and school-day limit use the app's non-blocking bottom notice pattern rather than trapping score entry in modal alerts.
- Dark-mode SF2 status-cell contrast checks exceed WCAG AA normal-text target in tested combinations (approximately 6.1:1+); primary SF2 table text uses the existing v1.0.27 semantic theme tokens.
- Existing local JSON persistence/export backup path automatically includes SF2 data; no new external/cloud dependency is introduced.
- Existing v1.0.27 user data remains compatible: SF2 structures are created lazily, and sf2Enabled defaults off for pre-existing classes.

FINAL RESULT: 5/5 PASSED — READY FOR WINDOWS INSTALLER BUILD / LOCAL TESTING
