E-Class Record App with GS and SF9
v1.1.1 — SF2 Input / Metadata Regression Fix
Five-Pass Release Gate

Scope
-----
Patch-only release on the v1.1.x SF2 line. The defect in v1.1.0 was isolated to official-output metadata validation: class.meta.sf2Enabled is a boolean, while both the SF2 validator and the shared ECR/GS validator accepted only string/number metadata. Because renderer payloads spread class.meta, sf2Enabled caused Official SF2 to fail with "Invalid SF2 metadata field: sf2Enabled" and could also break ECR/GS official output.

Patch
-----
- main-extension.js only: permit a boolean value specifically when metadata key === "sf2Enabled".
- Unrelated boolean metadata remains rejected.
- Object/array metadata remains rejected.
- No app.js, main.js, preload.js, updater, grading, attendance, SF9, persistence, or template code changes.
